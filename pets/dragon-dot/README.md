# Codex 宠物：白龙娘 Dot 版

白发紫瞳龙娘，手托蓝色黑帽 Dot 图标。

## 安装

需要已安装、已开放宠物功能的 Codex 桌面客户端。解压后打开 `install.html`，点击“在 Codex 中安装”，在浏览器与客户端确认，再到设置的宠物列表中选择。Windows 也可双击 `Install-Codex-Pet.url`。首次安装需要联网访问 GitHub。

解压不会自动启用宠物。安装入口按[官方 OpenAI 安装链接协议](https://learn.chatgpt.com/docs/reference/commands#pets)生成，使用 v2 格式；客户端不支持该入口时，请先更新客户端并确认宠物功能可用。

`spritesheet.png` 为透明精灵表；`previews/` 为 GIF、MP4 和关键帧；`metadata.json` 为格式及校验信息。

精灵表为 v2，1536 × 2288 像素，每格 192 × 208，包含九种状态及十六个视线方向。
